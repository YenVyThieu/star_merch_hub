# Reaching the Little Sun ☀️

Reaching the Little Sun is an e-commerce web application for
buying and exploring merchandise from idols and celebrities.

The application was created for CPAN-228 Web Application Development.

## Developer

Yen Vy Thieu

## Deliverable 1 Features

- Spring Boot web application
- Thymeleaf templates
- Bootstrap responsive design
- Product creation form
- Server-side validation
- Spring Data JPA
- H2 database
- Sample data using data.sql
- Product filtering by artist and category
- Product sorting by name and price
- Pagination
- Yellow "Reaching the Little Sun" visual theme

## How to Run

Run:

./mvnw spring-boot:run

On Windows:

.\mvnw.cmd spring-boot:run

Then open:

http://localhost:8080
